## Git használati szabályok
- egy közös Git repository
- a HTML és CSS fájlok verziókezelve vannak
- több, elkülönülő commit készül
- érthető commit üzeneteket használunk

✅Jó commit üzenetek például:
- MI bemutató oldal szövegének elkészítése
- Bootstrap navbar és grid rendszer hozzáadása
- CSS alap formázások

❌Nem elfogadható például:
- „update”
- „final”
- „kész”

## Fontos szabályok
- MI által automatikusan generált HTML, CSS vagy PowerPoint **nem fogadható el**
- Word dokumentumok, bemutatók **nem kerülnek a Git‑be**, külső megosztott mappából érhetők el
- Ami nem igazolható commitokkal és magyarázattal, az nem értékelhető
